## 目标

机构端 Web 管理后台（Vue 3 + Element Plus），覆盖登录、基础数据管理、AI 经营助手（核心）、知识库、积分计费、看板。

## 任务分解

### 8.1 脚手架（替换占位包）

- `apps/admin` 初始化：Vite + Vue 3 + TypeScript + Element Plus + Pinia + Vue Router
- axios 封装：请求自动带 Bearer token；401 自动跳登录页
- 引用 `@artedu/shared` 复用类型/错误码

### 8.2 登录与布局（任务 3.1）

- 登录页：账号密码 → `/api/auth/admin-login`
- 主布局：侧边栏 + 顶栏 + 面包屑
- 路由守卫：未登录跳转登录页
- token 过期自动 refresh

### 8.3 基础数据页面（任务 3.2）

- 机构信息配置
- 老师账号管理（增删改查、角色分配）
- 班级管理 + 学员档案（按班级/老师筛选，支持关联家长）

### 8.4 AI 经营助手（任务 3.3，核心）

- **AI 点评生成器**：选学员 → 输入课堂表现 → `POST /api/ai/report/generate` → 流式展示 → 人工编辑 → 保存
- **AI 招生文案**：输入机构特色 → 生成 → 一键复制
- **AI 对话**：fetch + ReadableStream 接收 SSE，打字机效果
- **关键**：发起计费请求时前端生成 `bizId`（nanoid），网络重试复用同一 bizId，防重复扣费

### 8.5 知识库管理（任务 3.4）

- 文档拖拽上传（进度条）
- 文档列表：状态标签（待处理/已索引/失败）

### 8.6 积分与看板（任务 3.5、3.6）

- 积分余额、消耗流水、充值操作
- 计费单价配置（point_prices）
- Agent 配置管理（provider/bot/Prompt 在线编辑）
- 额度预警（低于阈值站内提示）
- ECharts 看板：调用次数、积分趋势、活跃学员

## 验证清单
