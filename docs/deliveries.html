阶段 3：鉴权模块

已完成 commit：feat: 阶段3 认证鉴权与RBAC（5405700） 日期：2026-09-16

交付内容

  • auth.jwt.ts：issueTokens（access 2h + refresh 7d，type 声明防混用）、refresh 存 Redis auth:refresh:{userId}（EX 7 天）
  • auth.service.ts：adminLogin（bcrypt、parent 拒绝、防账号枚举）、wxLogin（code2session + upsert）、refresh（Redis 一致性校验）、logout、me
  • 登录前查询解法：runInLoginContext 显式注入临时上下文
  • 5 接口：admin-login / wx-login / refresh / logout / me
  • RBAC：requireAuth（40001）+ requireRole（admin3 > teacher2 > parent1，不足 40003）

验证结果

  • admin-login 返回 access + refresh 双 token
  • /api/auth/me 带 token 正常；错 token 返回 40001
  • logout 后旧 refresh 调 /refresh 失败（吊销生效）
  • Redis 可查 auth:refresh:{userId}，TTL 约 604791 秒
  • 错误密码 40001；parent 越权 40003 留待阶段 6 业务接口验证

关键决策

refresh payload 携带 tenantId / role（plan 示意仅 userId）：否则刷新时无租户上下文无法重新签发，避免每次刷新查库。

关键决策

修复 plan.md 失败路径账目缺陷：plan 6.4 中 consume 流水仅在 AI 成功时写入，失败路径只写 rollback 正向流水（+amount）而无对应负向流水——流水聚合比真实余额多出回滚金额，对账会把差额"修复"进 Redis，每次 AI 失败都白送用户积分（实测复现：真实余额 899 被修复为 949）。修复：rollbackPoints 回滚时先补写原扣减的 consume 流水（-amount，占住 uk_biz 幂等位），再写 rollback 反向流水，借贷相抵。
BullMQ v6 API 适配：Queue.add 已移除 repeat 选项，改用 upsertJobScheduler 注册每 60 秒对账任务。

验证结果

  • 机构信息查询与更新：name / contact 修改生效
  • 班级 CRUD 全流程：创建 → list 返回 studentCount=1（groupBy 统计正确）→ 更新
  • 学员 CRUD：创建关联班级 → list 组装 className → 修正关联 → 更新
  • 用户创建：teacher 账号创建成功，返回数据不含 password
  • parent 越权拦截（补验阶段 3 遗留项）：调 user/list、student/list、dashboard/summary 均返回 403 40003
  • parent 报告行级过滤：report/list 返回 200 空列表；传他人 studentId 查不到数据；detail 对非本人学员 403
  • teacher 调 dashboard/summary 返回 403 40003（admin 专属）
  • dashboard/summary：聚合统计与近 7 日趋势（reportTrend / consumeTrend）返回正常
  • ai/agents：全局 3 行 + 租户自定义行合并，isCustom 标记正确；ai/logs 分页正常
  • pnpm -r build 与 pnpm lint 全绿

关键决策

软删实现：phase-6 文档描述 deleted_at 字段与 schema 不符，遵循 schema 用既有 status=0 语义（不改动已完成的数据层）。
schema 无 @relation 关联：Class/Student/AiReport 间无法 include，班级学员数用 groupBy(classId) + Map 组装，className/studentName 手动二次查询。
parent 行级过滤三分支：传指定 studentId 时校验归属、否则限定其学员集合、无关联学员直接返回空，防止家长 A 传家长 B 的 studentId 水平越权（RBAC 管不到行级）。
PowerShell 5.1 中文编码坑：Invoke-RestMethod 发中文 body 默认非 UTF-8 会乱码入库，必须 UTF8.GetBytes($json) + Content-Type 含 charset=utf-8。
